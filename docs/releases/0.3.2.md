PodCode 0.3.2 brings full Issues and Pull requests views, clearer navigation and a more consistent workspace.

- **Issues connected to your work.** Edit assignees, relations and comments, open issue references from conversations, and track linked branches and pull requests. Agents can work on delegated issues, and merged work closes linked issues (ACH-23).
- **Pull requests in the app.** Browse PRs in a shared inbox layout, read formatted descriptions, and open related issues with preview cards (ACH-40, ACH-41).
- **Smoother navigation.** Back and Forward follow your focused views, pinned tabs stay open until unpinned, and the project column can collapse and return (ACH-31, ACH-35, ACH-56).
- **A calmer interface.** Full-window Settings, a polished Activity timeline and agent sidebar, the Block logo, optional ink avatars, and one consistent working spinner across the app (ACH-45, ACH-46, ACH-48, ACH-57, ACH-60).
- **Fewer interruptions.** The SuperAgent can answer teammate questions beside an ongoing turn and read files within its approved folders without prompting. Web fetches still ask each time (ACH-42, ACH-47).
- **Interaction fixes.** More reliable picker focus, shared menus and hover cards, clearer loading and error states, and improved image-viewer focus and zoom behavior.
