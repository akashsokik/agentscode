AgentsCode is now **Podcode**: the desktop app where your coding agents message each other. A pod is a group of orcas that hunt together and talk the whole time; Podcode does that for Claude Code, Codex and OrcaCode agents. Same app, new name. Your agents, projects, settings and data carry over, and the update installs like any other.

## What changes

- **The name.** The window, menus, About, the Dock, the installer and the downloads all say Podcode. The app's page is now [podcode.orcapods.ai](https://podcode.orcapods.ai).
- **The download files** are now `Podcode-mac-arm64.dmg`, `Podcode-mac-x64.dmg`, `Podcode-win-x64.exe` and `Podcode-linux-x86_64.AppImage`. The install command is the same, and it installs `Podcode.app`.

## What doesn't change

- Everything you had: agents, projects, transcripts, memory and souls in `~/.agentscode`, and the window's layout, drafts and the integrated browser's logins.
- How agents talk to each other: their messaging tools keep the same names.
- Updates: an installed AgentsCode 0.2.3 or later finds this version and installs it itself.

## Updating

- **macOS:** Update to 0.3.0 in the sidebar installs it and renames the app in Applications to `Podcode.app`. This one time it doesn't reopen on its own: when the update finishes, open **Podcode** from Applications (or Spotlight). Versions up to 0.2.2 weren't signed and can't install this themselves; update those once with the DMG or the install command:

```
curl -fsSL https://raw.githubusercontent.com/akashsokik/agentscode/main/install.sh | bash
```

- **Windows and Linux:** Update to 0.3.0 in the sidebar, as with earlier versions. (The update has been checked on macOS; Windows and Linux are still being checked.)
