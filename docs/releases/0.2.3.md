AgentsCode 0.2.3 is the first Mac release signed with a Developer ID and notarized by Apple: the DMG from the website opens like any other app, and updates install themselves.

## Highlights

- **Signed and notarized on macOS.** No more "Apple could not verify AgentsCode" and no trip to System Settings > Open Anyway. A DMG downloaded in a browser opens after macOS's usual "downloaded from the Internet" prompt.
- **Mac updates install in place.** From 0.2.3 on, Update to X in the sidebar downloads the new version and restarts into it on a Mac too, like Windows and Linux already did.

## Updating from 0.2.2 or earlier on macOS

Earlier Mac builds were not signed, so they can't install this signed version themselves: they keep showing the install command instead. Update once by hand, either by downloading the DMG again and replacing the app in Applications, or from Terminal:

```
curl -fsSL https://raw.githubusercontent.com/akashsokik/agentscode/main/install.sh | bash
```

After that, updates install themselves. macOS may ask once more for access to folders you'd already allowed, because the app's signature changed.
