AgentsCode 0.2.5 is the first Mac release signed with a Developer ID and notarized by Apple, and it gives the app a calmer, flatter look: agents lead their lists, the transcript lines up on one edge, approvals read as plain sentences, and every agent gets a new avatar. The 0.2.3 and 0.2.4 tags were never published, so these notes cover everything since 0.2.2.

## Highlights

- **Signed and notarized on macOS.** No more "Apple could not verify AgentsCode" and no trip to System Settings > Open Anyway. A DMG downloaded in a browser opens after macOS's usual "downloaded from the Internet" prompt.
- **Mac updates install in place.** From this release on, Update to X in the sidebar downloads the new version and restarts into it on a Mac too, like Windows and Linux already did.
- **New avatars.** Twelve flat, tilted shapes with two pill eyes, in twelve colours now including olive and plum; the cloud is the SuperAgent's alone. Every agent keeps its colour and moves to the nearest new shape.
- **Agent-led lists.** The avatar leads each agent card, with name and role first and the state always at the right, under quiet Needs you, Working and Idle labels. Sidebar agent rows stay one line, with their status at the right.
- **A sidebar that folds.** Channels, Agents and Projects fold and carry a count, and say while folded whether something inside needs you or is working. Project rows show their agents' avatars, and the current project is marked by brighter text and an open folder. A channel with unread posts shows a "new" pill.
- **Lighter top and foot.** New agent is the one raised control, with Search beside it; the foot is one row (About you, Settings, Collapse). The folded rail shows counts instead of dots.
- **One-edge transcript.** Avatars hang in a narrow gutter so names, bubbles and prose share one left edge; headers read as a sentence with the time at the right.
- **Flat everywhere.** No shadows anywhere: the composer, popovers, dialogs and toasts are flat surfaces with borders. The composer has quiet toolbar buttons and shows key hints while you type.
- **Lighter overview.** The right panel's Overview drops nested boxes, folds empty sections into one line and shows the team's numbers in one row.
- **Plain-language approvals.** An approval reads as a sentence in the conversation instead of a card of raw JSON; reading a file or searching names the path. Enter allows and Esc denies, only for the first approval in the pane you are in, with a short guard so a double Enter never allows two things.
- **A new Home.** Home has a composer with agent chips, to send a message to any agent without opening it first.

## Updating from 0.2.2 or earlier on macOS

Earlier Mac builds were not signed, so they can't install this signed version themselves: they keep showing the install command instead. Update once by hand, either by downloading the DMG again and replacing the app in Applications, or from Terminal:

```
curl -fsSL https://raw.githubusercontent.com/akashsokik/agentscode/main/install.sh | bash
```

After that, updates install themselves. macOS may ask once more for access to folders you'd already allowed, because the app's signature changed.
