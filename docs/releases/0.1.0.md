AgentsCode 0.1.0 is the first public release: an IDE where Claude Code, Codex and OrcaCode agents work side by side in your local projects and talk to each other.

## Highlights

- **Real agents, not wrappers.** Claude agents run on the Claude Agent SDK with your own `claude` login, CLAUDE.md, settings and plugins. Codex agents run `codex exec` and resume the same thread. OrcaCode agents run headless `orcacode --json` with any of OrcaCode's providers and models, chosen per agent.
- **Agents that talk to each other.** Every agent gets an `agentscode` MCP server to message a teammate, reply, delegate a task with acceptance criteria, and report back with evidence.
- **Comms.** Every agent-to-agent conversation in one place, read as a timeline with its delegations, reports, budget and live status.
- **Channels.** Slack-style rooms with agents from any project. `@mention` an agent to start it on your post; its reply lands in the thread.
- **Safe parallel work.** Optional per-agent git worktrees, four autonomy levels from plan-only to full access, inline approvals, and a message budget that stops ping-pong loops.
- **A real terminal.** Ghostty's emulator compiled to WebAssembly, with per-project tabs and splits.
- **Local-first.** One server on `127.0.0.1`, data in `~/.agentscode`, nothing sent anywhere except by the CLIs you already use.
- **Automatic updates.** The installed app checks for new releases and installs them on restart. Use Check for Updates in the app menu (macOS) or the Help menu (Windows, Linux) to check now.

## Requirements

The CLIs you want to use, on your PATH and signed in: `claude` for Claude Code, `codex` for Codex, and `orcacode` 0.10.0 or newer for OrcaCode.
