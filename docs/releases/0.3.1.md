PodCode 0.3.1 brings a clearer Work view for following branches, reviewing changes, and seeing what has reached main.

## Work

- Switch between **Graph**, **Active**, and **Merged** for one project at a time. Each project remembers its view.
- Select a branch or commit to see its owner, recorded review, and changed files. Open a file to inspect its diff directly in Work.
- Use the sidebar for focused inspection or open Work as a full pane to keep the list and details side by side.
- See local-only merges separately from remote history and unknown remote status. Remote information reflects locally cached Git refs; refreshing Work does not fetch.
- Clean up merged branches and leftover agent worktrees from a quiet footer action. Removal still requires confirmation, and worktrees containing submodules are excluded from automatic cleanup.

## Naming and migration

- The app and download files now consistently use **PodCode**.
- Existing data moves from `~/.agentscode` to `~/.podcode`, with compatibility for earlier paths and settings.
- Agent tools use the `podcode` MCP name while continuing to accept older tool names.
- The installer recognizes an already-running app across the earlier bundle names.
